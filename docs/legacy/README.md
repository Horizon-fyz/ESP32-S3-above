## 二、约定

1. 本目录**必须纳入版本控制**, 不要加入 `.gitignore` —— 它是开发历史的组成部分。
2. 归档的是**文档 / 源码快照**, 不含构建产物 (`build/`、`sdkconfig`、`*.log`)。
3. 归档目录位于 `docs/` 下, **不参与构建** (根 `CMakeLists.txt` 的 `EXTRA_COMPONENT_DIRS` 只指向根 `components/`), 可安全长期保留。
4. 每次重大替换 (换板 / 换方案 / 大重构) 前, 按同样方式新增归档文件, 并在本 README 清单表中登记。
5. 更细粒度的历史建议配合 Git: 变更前提交一次或打 tag, 与归档互为备份。
